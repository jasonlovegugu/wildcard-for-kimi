# Wildcard for Kimi（wildcard-for-kimi）

Kimi Work 插件：在对话里浏览 Kimi Talk 及 Kimi 官方社区线下活动并完成报名。有效会员（含赠送）可授权读取本人 Kimi 订阅信息进行快速核验，达标走 Wildcard 免审直通通道；其余用户正常排队审核。

Wildcard 是通用的活动报名分层工具，本仓库为 KIMI 社区版本。报名与审核结果以主办方通知为准。

## 安装

仓库地址：**https://github.com/jasonlovegugu/wildcard-for-kimi**

把仓库链接或 zip 发给朋友，任选一种方式安装：

**方式一（推荐，插件页直装 GitHub 链接）**：打开 Kimi 桌面版插件页，点「＋ 自定义插件」，粘贴上面的仓库链接安装。装完即可在对话里使用，无需重启。

**方式二（本地 zip）**：下载仓库 zip 并解压（保证 `kimi.plugin.json` 在解压后目录的根部），然后在 Kimi 桌面版插件页「个人」页签通过本地入口安装。

> ⚠️ 不要用 `kimi-daimon kimi-plugin install` 命令行直装：这条底层命令不经过插件页的状态管理，装完后插件虽然在会话里生效，但在插件页不可见、无法更新或卸载（俗称"幽灵安装"）。曾经 README 推荐过该方式，已废弃。

## 更新

仓库推送新版本后，在插件页点「更新」即可同步。

## 运行要求

需要 `python3` 和 `curl`。直通通道的自动读取需要宿主具备日常浏览器控制能力；不具备时可按引导上传自行裁剪的套餐/有效期区域截图进行人工复核，普通通道不受影响。

## 使用

安装后直接用自然语言，例如：

- 最近有哪些 Kimi Talk 线下活动？
- 我想报名深圳站的 Kimi Talk
- 我是深度用户，帮我走免审直通通道报名

## 当前活动

活动清单由组织者人工维护在 `skills/wildcard-for-kimi/data/events.json`，只收录带真实可验证 Luma 链接的活动；新活动也会经 Luma 官方日历同步源自动发现。

## 隐私

报名会涉及姓名或联系方式；直通通道还涉及当前套餐、订阅有效期和经确认的裁剪截图。提交前会说明数据用途、接收方和保存规则并征得确认。详见[隐私政策](PRIVACY.md)。
